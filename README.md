# Смета за 5 минут

Самостоятельное веб-приложение для предпринимателей и офисных сотрудников: составление коммерческих предложений, смет закупок и расходов для руководителя.

## Открытие в Cursor

В Cursor выберите File → Open Folder и откройте эту папку `smeta-app`. Либо выберите File → Open Workspace from File и откройте `smeta.code-workspace`.

Открывайте именно папку `smeta-app`, чтобы работать с этим приложением как с отдельным проектом.

## Запуск

Дважды щёлкните по `index.html`. Установка зависимостей, npm и сервер не нужны.

## Возможности

- Автоматический расчёт позиций; добавление, удаление и добавление через Enter в последней строке.
- Скидка, НДС и выбор валюты: ₸, ₽, $, €.
- Комментарий и сохранение PDF через диалог печати браузера.
- Автоматическое сохранение черновика в localStorage.
- Новая смета с подтверждением и увеличением номера.
- Копирование текста для WhatsApp и поле для ручного копирования, если буфер недоступен.
- Официальное оформление и адаптация для телефона.

Данные остаются в браузере, приложение ничего не отправляет в интернет. Черновик из другой копии приложения может не перенестись автоматически при изменении пути или адреса сайта.

## Файлы

- `index.html` — страница, реквизиты, позиции и кнопки.
- `styles.css` — оформление экрана, мобильной версии и печати А4.
- `script.js` — расчёты, черновик, копирование и вызов печати.
- `AGENTS.md` — правила работы с проектом.
- `smeta.code-workspace` — открытие отдельного проекта в Cursor.

## Проверка

1. Добавьте позиции: 2 × 15 000 и 1 × 8 000. Итог: 38 000 ₸.
2. Укажите скидку 10 % и НДС 10 %. Сумма со скидкой: 34 200 ₸, НДС: 3 420 ₸, итог: 37 620 ₸.
3. Обновите страницу — поля и позиции должны восстановиться.
4. Проверьте копирование текста и предпросмотр через «Сохранить PDF».

## Размещение на GitHub

Эта папка подготовлена как отдельный проект, без скопированной истории `.git` и без подключения к удалённому репозиторию. Для загрузки открывайте терминал именно в `smeta-app`. Файлы `index.html`, `styles.css` и `script.js` должны находиться в корне нового репозитория.
